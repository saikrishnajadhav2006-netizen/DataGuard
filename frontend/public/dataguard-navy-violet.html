Frequently asked questions

Which languages are supported?

JavaScript, TypeScript, Python, Java and C++ to start, with more on the way.

Is my code kept private?

Your uploads stay inside your own account.

Can I trust the AI suggestions?

AI suggestions can be wrong, so always review a change before you apply it.

How does the GitHub App work?

Install DataGuard AI from GitHub and choose your repositories. When a pull request is opened, the app comments on it with the quality score and the issues it found. It works inside GitHub, so there is nothing to connect on this website.

Do I need an account?

Yes. You sign in once to upload a project or to use AI Radar.
